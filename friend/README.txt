# RustCraft

Мне нравится Rust, и я решил перенести часть его механик в Minecraft. Так появился RustCraft.

Мод для Minecraft 1.16.3 с механиками выживания в духе Rust. В проекте есть строительство, оружие, ресурсы, транспорт и NPC. Используется Forge 34.1.42.

## Игра с другом через Radmin VPN

Установите Radmin VPN и подключитесь к одной сети. Хосту нужно сообщить другу свой Radmin-IP, который начинается с `26.`. Версия игры и мода у обоих игроков должна совпадать.

### Для друга

1. Распакуй папку `friend` и запусти `PLAY-RustCraft.bat`.
2. Введи Radmin-IP хоста и свой ник. При первом запуске скачаются Java 8, Minecraft 1.16.3, Forge и нужные файлы.
3. Для следующих запусков используй тот же батник.

В комплекте лежит мод версии 0.2.0. `INSTALL-RustCraft.bat` устанавливает файлы без запуска игры, `UPDATE-RustCraft.bat` проверяет обновление. Автообновление сработает, только если хост отдельно запустил службу обновлений; иначе используется установленный мод. Чтобы поменять адрес хоста, удали `%LOCALAPPDATA%\RustCraft-1.16.3\radmin-host.txt` и запусти батник снова.

Лаунчер использует локальный ник без входа Microsoft и рассчитан на сервер с `online-mode=false`. В этом режиме имена не проверяются, поэтому играйте только с теми, кому доверяете. Для игры нужна своя законная копия Minecraft.

### Для хоста

Установи JDK 8, подключись к Radmin и запусти `START-SERVER.bat` из корня проекта. Дождись запуска сервера и отправь другу свой Radmin-IP и порт `25576`. При необходимости разреши входящий TCP-порт в брандмауэре для Radmin.

При первом запуске могут понадобиться интернет, принятие EULA в `server/eula.txt` и настройка `server.properties`. Для остановки введи `stop` в окно сервера. Мир хранится в папке `server`: сохрани её при обновлении. Батник сам не настраивает Radmin, брандмауэр и службу обновлений.

## Сборка

Нужен JDK 8. Укажи его в `JAVA_HOME` и выполни `gradlew.bat build`. Готовый JAR появится в `build/libs`. Экспериментальная версия 0.3.0 в комплект не входит.

Мод неофициальный. Перед публикацией проверь права на ресурсы проекта.
